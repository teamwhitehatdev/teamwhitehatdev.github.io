# XAMPP Local Webserver Setup Guide for WHITE HAT DEV

This folder (`xampp_ready/`) contains the complete compiled production web application configured specifically for **XAMPP (Apache Web Server)** testing on Windows/Linux/macOS.

---

## ⚡ Step-by-Step Instructions to Run on XAMPP

1. **Locate your XAMPP `htdocs` directory**:
   - Default Windows Location: `C:\xampp\htdocs\`

2. **Copy the `xampp_ready` Folder**:
   - Copy all contents inside `xampp_ready/` into a new folder:
     `C:\xampp\htdocs\white-hat-dev\`

3. **Start Apache in XAMPP Control Panel**:
   - Open XAMPP Control Panel and click **Start** next to **Apache**.

4. **Access in Web Browser**:
   - Open your browser and navigate to:
     👉 **[http://localhost/white-hat-dev/](http://localhost/white-hat-dev/)**
