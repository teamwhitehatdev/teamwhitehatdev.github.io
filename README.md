# WHITE HAT DEV - Elite Web & Mobile Engineering Portfolio & Storefront

![WHITE HAT DEV Banner](https://images.unsplash.com/photo-1526374965328-7f61d4dc18c5?w=1200&q=80)

**WHITE HAT DEV** is a high-end, responsive sci-fi cyberpunk web application featuring an interactive hacker portfolio, digital goods & merchandise marketplace, AI sales assistant, dynamic theme engine, Web Audio API sound FX, automated PayPal checkout, and cyber admin backend portal.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build Production Bundle
```bash
npm run build
```

### 4. Deploy to GitHub Pages (1-Click)
```bash
npm run deploy
```
